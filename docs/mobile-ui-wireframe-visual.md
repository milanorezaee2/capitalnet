# Visual Wireframe for Mobile UI

## Page Structure

[Top Bar]
- left: logo
- right: theme/search/menu icons

[Hero Card]
- large rounded card
- title
- subtitle
- primary CTA
- secondary CTA
- quick chips below

[Stats Row]
- 3 small cards horizontally aligned

[Services Section]
- section title
- 3 stacked cards

[Why Us Section]
- 2x2 grid of small cards

[Process Section]

[Testimonials]

[Blog Preview]

[FAQ]

[Final CTA]

## Visual Notes
- Keep content centered and compact
- Use strong spacing between sections
- Hero should dominate the top area
- Preserve app-like feel on mobile
- Each section should have a clear visual container
